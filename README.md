
# Road Accident Analysis Using Python and Machine Learning

## Project Overview
This project analyzes road accident data using Python, data visualization, and machine learning techniques to explore accident patterns and severity.

## Objectives
- Clean and preprocess the dataset.
- Perform Exploratory Data Analysis (EDA).
- Visualize accident trends and patterns.
- Apply regression and classification models.
- Evaluate model performance.
- Explore clustering and dimensionality reduction using K-Means, hierarchical clustering, and PCA.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn

## Project Files
- `road_accident_analysis.py` — Python analysis and machine learning code.
- `Road_Accident_Analysis_Project_Report_Final.docx` — Project report.
- `requirements.txt` — Required Python libraries.

## Installation
Install the required libraries using:

```bash
pip install -r requirements.txt
```

## How to Run
1. Download or clone this repository.
2. Place the dataset in the project folder.
3. Update the dataset path in the Python script if required.
4. Run:

```bash
python road_accident_analysis.py
```
